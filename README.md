# ♻️ ReCircle Sustainability Network

A Full-Stack (MERN) web application built to connect households and waste collectors, promoting a circular economy and sustainable environment.

### 🚀 Live Demo
[Click here to view the live website](https://re-circle-sustainability-network.vercel.app)

### 💻 Tech Stack
* **Frontend:** React.js, Tailwind CSS, Vite
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Deployment:** Vercel (Frontend), Render (Backend)

### ✨ Key Features
* Secure User Authentication (JWT & Cookies)
* Role-based access (Household vs. Collector)
* Real-time waste collection requests
* Fully responsive and modern UI

### 🛠️ How to run locally
1. Clone the repository
2. Run `npm install` in both frontend and backend folders
3. Create a `.env` file in the backend with your MongoDB URI and JWT Secret
4. Run `npm run dev`
